RTOS Pizza

A FreeRTOS-based embedded firmware project developed on the RP2350, modelling a pizza preparation workflow through concurrent tasks, semaphore-based synchronization, and a central coordinator task.

Project Type University Group Project
Role Firmware Development · System Integration
Date Oct 2025 – Feb 2026

Overview

Exploring concurrent task execution with FreeRTOS

RTOS Pizza was developed as a university group project to explore real-time operating system concepts using FreeRTOS on the RP2350 microcontroller platform.

The system models a pizza preparation workflow using multiple concurrent tasks. Separate tasks simulate preparation activities for dough, sauce, and cheese, while a central "Chef" task coordinates the workflow and waits for all parallel activities to complete before continuing with the sequential assembly process.

Rather than controlling physical robots, the project uses software tasks to demonstrate how a real-time system can coordinate multiple activities running concurrently.

Engineering Challenge

Working with a relatively new microcontroller platform

One of the practical challenges during development was working with the RP2350 platform at a relatively early stage of its adoption.

Compared with more established Raspberry Pi microcontroller platforms, fewer examples and reference materials were available for some of the development requirements at the time.

This meant that part of the development process involved setting up the Pico SDK environment, identifying the appropriate libraries and project configuration, and working through the available documentation to get the firmware running correctly on the target platform.

Challenge

Limited reference material for the relatively new RP2350 platform.

Approach

SDK setup, library integration, documentation research, iterative development and testing.

System Architecture

A fork-join workflow

The firmware uses a central coordinator to launch parallel preparation tasks and synchronize their completion before moving into the sequential assembly stage.

Execution flow

COORDINATOR

Pizza Chef Task

Creates the synchronization mechanism, launches the worker tasks, waits for their completion, and coordinates the assembly stage.

↓ launches parallel tasks
PARALLEL TASKS

↓ completion signals through counting semaphore
SYNCHRONIZATION

Assembly Workflow

The system proceeds through the remaining pizza preparation stages in sequence.

Technical Implementation

FreeRTOS primitives in embedded C

FreeRTOS Tasks

Separate tasks were used to represent the concurrent preparation activities, allowing multiple simulated operations to execute under the RTOS scheduler.

Counting Semaphore

A FreeRTOS counting semaphore was used as a synchronization barrier, allowing the coordinator to wait until all three preparation tasks had completed.

Dynamic Task Lifecycle

Worker tasks are created for each order cycle and removed after completing their simulated work, demonstrating dynamic task management.
